Pole-to-BoQ Trainer

APDCL · SoR 2021-22 · structure by structure

Every main item drags a set of companions into the estimate. When you write the main item, write its companions in the same breath. Tap a card to test yourself before revealing.

Give the field-visit picture (route length, special structures, DTR) and the builder adds up the structure kits into one bill of materials. It shows how each count was reached, so you can check it against the site.
