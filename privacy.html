Pranju OS — privacy

Pranju OS is a personal app used only by its owner, Pranju Chakrapani.

When Google Drive is connected, the app uses the drive.file permission to save and read only the files it creates itself (Travel Trace GPS days and memory photos) in the owner's own Google Drive. It cannot see any other file in the Drive.

No data is sold, shared or shown to anyone else. The connection can be removed at any time from Travel Trace (Disconnect) or from the Google Account's security settings.
